# Marketing Command Center — Complete OS

Final single-page web app covering the full Marketing Department Operating Manual.

## Live backend
- Supabase project: `Marketing KPI Command Center`
- Auth: Supabase Auth
- Authorization: RLS + existing employee/profile hierarchy
- Frontend uses publishable key only

## Modules
Dashboard, Action Center, Alerts, Strategy, Plans, Campaigns, Personas, Customer Insight, Competitors, Content, Ads Performance, Digital Growth, Marketplace, Events, Leads, Sales Pipeline, CRM/Customers, Budget, KPI, Experiments, Learning, Tasks, Requests, Approvals, QA, Risk/Crisis, Assets, Knowledge, Vendors, Skill Matrix, Users & Roles, Integrations, Audit Log, Manual Map, Settings.
